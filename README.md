# AtomHax

HaxBall client - Early Access.

## Download

Get the latest release from [Releases](https://github.com/2Gbps/AtomHax/releases).

## Features

- Custom dark glass UI + sidebar
- Room search + auto-join
- Engine bridge API (dynamic patching of game-min.js, active only when hax-script.js is imported and enabled)
- 20x frame generation at a 360 fps cap with paint suppression
- 0.8x stroke scaling
- Canvas/DOM performance optimizations
- reCAPTCHA auto-solver
- Discord Rich Presence
- Automatic updates (downloads + relaunches itself)
- Client code obfuscated

## Usage

1. Download `AtomHax-<version>-x64.exe` from Releases
2. Launch and play
3. Import `hax-script.js` via Scripts menu for BlockHelper / kick macro / OP mode
4. Toggle it ON to activate
