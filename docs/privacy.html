1 · Summary

Short Version

AtomHax is a free, open-source desktop client. The project operates no backend, collects no analytics, requires no account, serves no ads, and sells nothing. Data that is attributable to AtomHax lives on your computer: your preferences, your imported scripts, and your browser cache.

A client without servers cannot be private on its own — the game traffic goes where the game sends it, and this page maps exactly which third parties touch data, and when.

The one-line answer: AtomHax itself sends nothing to anyone, keeps everything local, and every third-party connection it does make is listed below.
2 · atomhax website

This Website

This site is static and hosted by GitHub Pages. AtomHax sets no cookies and embeds no analytics. GitHub, as the host, processes standard web server logs (such as IP address and request metadata) for its own security and operations under GitHub's privacy statement.

Your browser loads two shared assets from third parties — typefaces from Google Fonts and an icon stylesheet from cdnjs — meaning those providers see the requests, and with them your IP address, whenever the site is opened.

3 · Desktop client

The Client

The client's job is to load the HTML5 game from haxball.com and run it with local performance and interface enhancements. All game traffic — authentication and nicknames, room hosting, live match data over websocket relays — flows between you and haxball.com's infrastructure, or between you and the peers your game session connects you to. That traffic belongs to haxball.com's systems and is governed by haxball.com's privacy practices.

No AtomHax backend sits in that path. The client has no telemetry channel, no update-ping home, and no crash reporting to the project.

4 · Local files

Stored on Your Computer

The client keeps everything environment-local inside its application data folder (%APPDATA%\atomhax\):

  • preferences.json — your client settings, such as performance limits.
  • scripts.json — the extensions you imported and whether each is enabled.
  • Browser cache and website data — the Chromium profile the client runs on, holding whatever the game's pages (haxball.com) store there, including any cookies it sets.

Imported scripts execute locally with the client's permissions, the same as any JavaScript you run in a browser tab. Review a script's code before loading it, and treat scripts from untrusted sources the way you treat programs from untrusted sources.

5 · Ecosystem map

Third Parties When You Play

6 · Control

Your Choices

  • Reset the client at any time by deleting %APPDATA%\atomhax\ while the client is closed — preferences, scripts, and cached site data go back to factory state.
  • Manage or remove any imported script in the client's script manager, or delete its entry from scripts.json.
  • The game's chat and rooms are public spaces run by other people — share personal information there as in any public forum: only as much as you want anyone to have.
